دليل نشر واستضافة موقع البوابة على السيرفر

اختر الطريقة الأنسب لبيئة السيرفرات لديك لنشر الموقع وإتاحته لجميع موظفي الـ 50 فرعاً فورياً.

ℹ

طبيعة الموقع التقنية

الموقع مبني بتقنيات الويب القياسية الصرفة (Static HTML5 / CSS3 / Vanilla JS)، وهو خفيف جداً، فائق السرعة، ولا يتطلب أي قاعدة بيانات أو إعدادات برمجية معقدة. كل ما تحتاجه هو وضعه خلف أي خادم ويب (Web Server).

1

الخيار الأول: النشر عبر Nginx على سيرفر لينكس (الأكثر شيوعاً)

إذا كان السيرفر يعمل بنظام Ubuntu / Debian:

  1. قم بنسخ كامل مجلد portal إلى مسار الويب في السيرفر: /var/www/ismart-portal
  2. تأكد من وجود ملفات الـ (EXE و APK و MP4) داخل المجلد الفرعي /var/www/ismart-portal/downloads/
  3. أضف إعداد Nginx في ملف /etc/nginx/sites-available/ismart-portal:
server {
    listen 80;
    server_name portal.yourcompany.local 192.168.1.100;
    root /var/www/ismart-portal;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # السماح بتحميل ملفات الفيديو والتثبيت الكبيرة
    client_max_body_size 500M;
}

ثم قم بتفعيل الإعداد وإعادة تشغيل Nginx:

sudo ln -s /etc/nginx/sites-available/ismart-portal /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl restart nginx
2

الخيار الثاني: النشر عبر Windows Server (IIS)

إذا كان خادم الشركة يعمل بنظام Windows Server:

  1. افتح IIS Manager (Internet Information Services).
  2. انسخ مجلد portal إلى المسار: C:\inetpub\wwwroot\portal.
  3. اضغط كليك يمين على Sites ➔ Add Website.
  4. حدد الاسم: iSmart Portal، والمسار المادي (Physical path): C:\inetpub\wwwroot\portal، والمنفذ المفضل (مثلاً Port 80 أو 8080).
  5. اضغط OK وسيعمل الموقع فوراً لجميع الأجهزة المتصلة بالشبكة!
3

الخيار الثالث: النشر عبر Docker في ثوانٍ معدودة

إذا كنت تستخدم Docker على السيرفر، يمكنك تشغيل حاوية Nginx فورية بسطر أوامر واحد فقط:

docker run -d --name ismart-portal -p 8080:80 -v /path/to/portal:/usr/share/nginx/html:ro nginx:alpine
✓

قائمة التحقق قبل مشاركة الرابط مع الفروع

  • ✅ تأكد من أن الرابط يفتح بسلاسة من أجهزة الفروع خارج المقر الرئيسي (عبر VPN أو IP الفرع).
  • ✅ جرب الضغط على زر تحميل الـ EXE للتأكد من تنزيل ملف الويندوز بدون أخطاء.
  • ✅ جرب الضغط على زر تحميل الـ APK من هاتف محمول للتأكد من اكتمال التنزيل.
  • ✅ جرب تشغيل مقطعي الفيديو وتأكد من عمل الصوت والصورة بوضوح.
