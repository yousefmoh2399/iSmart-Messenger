1. نظرة عامة

تطبيق iSmart Messenger هو حل مؤسسي مخصص لبيئات العمل والشركات، يجمع بين المراسلة الفورية، ومسح المستندات ضوئيًا وتحويلها إلى PDF، وجرد وإدارة أصول تكنولوجيا المعلومات، ونقل الملفات والطباعة الداخلية. خصوصية وأمان بياناتك هي أولويتنا القصوى.

2. البيانات التي يتم التعامل معها

  • الكاميرا: تُستخدم حصريًا لمسح المستندات الورقية وتطبيق خوارزميات OpenCV لتحسين الصورة وقراءة الباركود وQR للأصول. لا يتم فتح الكاميرا في الخلفية مطلقًا.
  • الميكروفون: يُستخدم فقط عند تسجيل المستخدم لرسائل صوتية داخل الدردشة الداخلية بضغطه على زر التسجيل.
  • الصور والمستندات: للوصول إلى الصور والمستندات التي يحددها المستخدم فقط لرفعها كمرفقات أو حفظ ملفات PDF الممسوحة محليًا.
  • بيانات الحساب: اسم المستخدم، الاسم الكامل، الصورة الشخصية، ودور المستخدم الوظيفي بهدف مصادقة تسجيل الدخول وعرض الهوية للزملاء.
  • عنوان الخادم: رابط API الذي يدخله المستخدم للاتصال بخادم شركته أو الخادم الافتراضي.
تعهد واضح: نحن لا نبيع، ولا نؤجر، ولا نشارك أي بيانات شخصية أو مستندات أو سجلات محادثات مع أي شركات إعلانية أو جهات تسويقية خارجية. التطبيق خالٍ تمامًا من أي إعلانات تجارية.

3. الأذونات المطلوبة وسببها

الصلاحية الغرض الأساسي
الكاميرا (Camera) مسح المستندات الورقية ضوئيًا وقراءة أكواد QR والباركود.
الميكروفون (Microphone) تسجيل الرسائل الصوتية داخل المحادثة بناءً على طلبك.
الصور والوسائط (Media Library) اختيار الصور والمستندات لإرسالها أو استيرادها للمسح.
الإشعارات (Notifications) تنبيهك بوصول رسائل عمل جديدة أو تحديثات على المهام.
الإنترنت وحالة الشبكة الاتصال الآمن بخادم النظام ومزامنة الرسائل والملفات.

4. تخزين البيانات وحمايتها

يتم تخزين رموز المصادقة والبيانات الحساسة محليًا على جهازك باستخدام بيئات التخزين الآمنة المشفرة (Secure Storage / Keystore / Keychain). يتم نقل جميع البيانات عبر تشفير TLS/HTTPS و WebSockets الآمنة.

5. حذف الحساب وإزالة البيانات

يتم إدارة الحسابات في التطبيق مركزيًا بواسطة مسؤولي النظام (IT Administrators) داخل مؤسستك. يحق لأي مستخدم في أي وقت طلب حذف حسابه وكافة بياناته الشخصية ومرفقاته وسجلات محادثاته. يمكن طلب الحذف عبر التواصل مع مسؤول النظام الداخلي أو مراسلتنا مباشرة على البريد الإلكتروني أدناه، ويتم حذف البيانات نهائيًا خلال 30 يومًا من تاريخ الطلب.

6. خصوصية الأطفال

التطبيق مخصص وموجه حصريًا لبيئات الأعمال والموظفين البالغين (18 عامًا فأكثر)، ولا يجمع أي معلومات عن الأطفال تحت سن 13 عامًا.

1. Overview

iSmart Messenger is an enterprise workplace communication and productivity application combining instant team messaging, OpenCV-powered document scanning and PDF generation, IT asset tracking, and workplace file relays. Your privacy and data security are our top priorities.

2. Data We Process & Purpose

  • Camera: Used strictly for scanning paper documents, auto-detecting boundaries with native OpenCV image processing, and scanning QR/barcodes for asset management. No background camera access occurs.
  • Microphone: Accessed solely when recording voice notes inside workplace chat upon user action.
  • Photos & Media Files: Accessed only to allow users to select images/documents as attachments or save scanned PDF outputs locally.
  • Account Credentials: Username, full name, profile photo, and role to authenticate users and identify colleagues within the workplace directory.
  • Server Address: Configurable backend API URL provided to connect to the organization's dedicated backend.
Zero Tracking & Advertising: We never sell, lease, or monetize personal information, chat transcripts, or documents. The application is 100% ad-free and tracker-free.

3. Permissions Breakdown

Permission Purpose
Camera Document boundary scanning, image enhancements, and QR/barcode decoding.
Microphone Recording chat voice messages on demand.
Photos & Storage Attaching workplace files and saving generated PDFs to device storage.
Notifications Alerting users about new messages and task assignments via Firebase Cloud Messaging.
Network & Internet Establishing encrypted connections (TLS/HTTPS & WSS) with the backend API.

4. Data Storage & Security

Authentication tokens are securely stored locally via encrypted hardware-backed storage (Android Keystore / iOS Keychain). All communication in transit is encrypted using HTTPS/TLS protocols.

5. Account & Data Deletion

Because accounts are provisioned by enterprise administrators, you may request the full deletion of your profile, messages, and uploaded files at any time by contacting your organization's IT administrator or sending an email request to our support address below. Data is purged within 30 days of confirmation.

6. Children's Privacy

This service is strictly intended for adult workplace employees (18+) and does not knowingly collect information from children under 13.
