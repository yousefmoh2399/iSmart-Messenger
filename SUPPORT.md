# iSmart Messenger Support

Welcome to the **iSmart Messenger** support page.

iSmart Messenger is a free, secure communication and document workflow client. The application connects to a compatible server instance that you operate yourself or are authorized to use by your organization or system administrator.

---

## Troubleshooting & Getting Started

If you experience issues connecting or using the app, please check the following basic troubleshooting steps:

1. **Check Internet Connectivity**  
   Ensure your device is connected to the internet (via Wi-Fi or cellular mobile data) or has access to your local network if using an internal workplace server.

2. **Verify Server URL**  
   Verify that the server address configured in the app is correct, includes the proper protocol (`https://` or `http://`), and has no typographical errors or trailing spaces.

3. **Contact Your Server Administrator**  
   For authentication issues, account provisioning, password resets, or server downtime, please reach out to your server administrator or organization's IT department.
